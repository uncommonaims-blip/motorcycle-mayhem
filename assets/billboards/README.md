# Motorcycle Mayhem billboards

Upload three standalone billboard textures to this folder on `main` using these exact filenames:

- `fighter-jet.jpg` — Take to the Skies: pilot a fighter jet and battle alien invaders
- `tropical-island.jpg` — Tropical Island Run
- `motorcycle-upgrade.jpg` — Upgrade Your Ride

Use flat, rectangular artwork without billboard frames, poles, or scenery outside the ad. Target aspect ratio: **2.5:1** (for example, 1500 × 600 pixels).

The game automatically cycles through these three files. Until uploaded, the in-game billboard uses a fallback image.
